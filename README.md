# Hub – Personal Command Center

Мой личный командный центр для быстрого запуска рабочих процессов.  
Настраиваемый, с веб-панелью в стиле Stream Deck.

## Возможности
- 🚀 Запуск команд из терминала
- 🖥️ Веб-панель с кнопками
- ✏️ Редактирование команд в браузере
- 🌐 Открытие ссылок в Brave
- 📱 Запуск приложений

## Установка
```bash
git clone ...
cd hub
python -m venv .venv
source .venv/bin/activate
pip install -e .
hub init
